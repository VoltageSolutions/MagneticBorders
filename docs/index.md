# Magnetic Borders

<img width="128" align="right" src="./assets/images/logo.png" alt="Magnetic Borders icon">

Magnetic Borders is a small Windows utility made to help with managing window tiling. When two windows touch, you can drag the border between them and both resize together.

Windows Snap resizes snapped windows together when you drag the line between them, but only for its built-in layouts. [FancyZones](https://learn.microsoft.com/en-us/windows/powertoys/fancyzones), included in [Microsoft PowerToys](https://github.com/microsoft/PowerToys), lets you create custom window tile layouts, but each window then resizes on its own. Magnetic Borders adds the missing piece: any windows whose edges touch resize together while you drag one of them.

I built Magnetic Borders to stay out of your way. It doesn't use the modifier keys Shift, Ctrl, Alt, or Win, so utilities like FancyZones and Grab And Move keep working as before.

## Run it

Download the latest release from [GitHub](https://github.com/VoltageSolutions/MagneticBorders/releases). it is a portable build - run the app where it is, or move it to a folder of your choice.

## Configure it

Magentic Borders lives in the Notification area of your taskbar (the system tray). Click on the magnet icon to access a quick configuration toggle, or select to open the full Settings menu.
